# 高程与 OOP 的通用约定

## 当次材料决定限制

本文件不是固定的知识点或头文件白名单。不默认禁止或允许指针、引用、结构体、类、函数或 STL；根据每次 PPT、PDF、题目和附件逐题确认。

检查全局变量、goto、string、STL、输入输出库、数组维数与访问形式、函数签名、变量数量和语句行数。材料未说明的限制明确记录，不沿用旧作业规则。

## 文件与输出

- 课程源程序默认 GBK，交付前重新解码检查中文。当次明确要求优先。
- 大括号独占一行、控制体保留大括号、四空格缩进，运算符两侧留空格。
- 文件名、语言、模板、预置数据和可修改位置以题目为准。
- 提示、标点、精度、空行和末尾换行依据题目、demo 和本次用户约定，不添加解释性输出。

## 验证范围

- `gaocheng` 使用本地编译器，不启用 SJOOP Linux SSH 功能。
- 只有 `oop` 可以选择 Linux；其连接、上传和远程运行须在当次 OOP 验证范围内。
- 只运行当次要求的目标；每个实际要求的目标检查真实编译日志是否零错误、零警告。
- 每题测试数据独立，运行与比较核心复用 `scripts/demo_compare.py`；不以各编译器互相输出相同代替 demo 对拍。
- `txt_compare --trim right` 不忽略行首、行中空白、空行或换行差异，不使用数值容差替代字符一致。使用前可执行 `probe` 核实比较器版本语义。
- 无输入题完整比较预置输出，临时数据实验结束后恢复指定数据。
- 未执行、连接失败、超时或有编译警告的检查不得宣称通过。

## 工作目录

源码与测试数据、运行记录、凭据配置分开保存。只交付指定文件；SSH 私钥和口令保存在使用者自己的环境，不写入可分发技能或公共仓库。
